# บอทสัญญาณเทรนด์ SET50 + คริปโต → Discord

บอทเช็กหุ้น SET50 และคริปโต Top 10 วันละครั้ง แล้วส่งสัญญาณ **ซื้อ** (และ **ออก**) เข้าห้อง Discord ของคุณ
คุณตัดสินใจกดซื้อเองในแอปโบรกเกอร์ / Bitkub / Binance — บอทไม่แตะเงินของคุณ

ทั้งหมดใช้ฟรี: ข้อมูลราคาจาก Yahoo Finance · รันบน GitHub Actions · แจ้งเตือนผ่าน Discord Webhook

---

## กลยุทธ์ (กราฟรายวัน)

สัญญาณซื้อ เมื่อครบทุกข้อในวันเดียวกัน
1. EMA20 ตัดขึ้นเหนือ EMA50
2. ราคาปิดอยู่เหนือ EMA200 (เทรนด์ใหญ่เป็นขาขึ้น)
3. วอลุ่มมากกว่า 1.2 เท่าของค่าเฉลี่ย 20 วัน
4. RSI(14) ต่ำกว่า 75 (ยังไม่ร้อนแรงเกิน)

ทุกสัญญาณซื้อจะบอก **จุดตัดขาดทุนแนะนำ** = ราคาปิด − 2 × ATR(14)
สัญญาณออก = EMA20 ตัดลงใต้ EMA50

เวลาส่งแจ้งเตือน
- หุ้นไทย: 18:00 น. จันทร์–ศุกร์ (ถ้าเป็นวันหยุดตลาด บอทจะแจ้งว่าไม่มีแท่งใหม่)
- คริปโต: 07:15 น. ทุกวัน (หลังแท่งรายวันปิด)

GitHub อาจรันช้ากว่าเวลาที่ตั้งไว้ 5–30 นาทีในช่วงคนใช้เยอะ — เป็นเรื่องปกติ

## ติดตั้ง (ทำบนคอมพิวเตอร์ ใช้เวลา ~15 นาที)

### 1) สร้าง Discord Webhook
1. เปิด Discord → สร้างเซิร์ฟเวอร์ของตัวเอง (กด + ด้านซ้าย) → สร้างห้อง เช่น `#signals`
2. คลิกเฟืองข้างชื่อห้อง → **Integrations** → **Webhooks** → **New Webhook**
3. กด **Copy Webhook URL** เก็บไว้ (อย่าแชร์ให้ใคร ใครมีลิงก์นี้ส่งข้อความเข้าห้องได้)

### 2) สร้าง repo บน GitHub
1. สมัคร/ล็อกอิน github.com → **New repository** → ตั้งชื่อ เช่น `signal-bot` → เลือก **Private** → Create
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
   - ต้องมีโฟลเดอร์ `.github/workflows/signals.yml` ด้วย (โฟลเดอร์ที่ขึ้นต้นด้วยจุดอาจถูกซ่อนบน Mac/Windows ให้เปิดดูไฟล์ซ่อนก่อน
     หรือสร้างไฟล์ใหม่บน GitHub โดยพิมพ์ชื่อ `.github/workflows/signals.yml` แล้ววางเนื้อหาลงไป)
3. กด **Commit changes**

### 3) ใส่ Webhook เป็นความลับ
repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
- Name: `DISCORD_WEBHOOK_URL`
- Secret: วาง URL จากขั้นที่ 1

### 4) ทดสอบ
repo → แท็บ **Actions** → เลือก **trading-signals** → **Run workflow**
- ครั้งแรกเลือก mode = `signals`, days = `10` → จะเห็นสัญญาณย้อนหลัง 10 แท่งเด้งเข้า Discord
- จากนั้นลอง mode = `backtest` เพื่อดูผลทดสอบย้อนหลัง ~10 ปี

เสร็จแล้ว บอทจะรันเองตามเวลาทุกวัน

## ปรับแต่ง
แก้ที่ส่วน "ตั้งค่า" ด้านบนของ `signal_bot.py`
- `SET50` — รายชื่อปัจจุบันเป็นรอบ ก.ค.–ธ.ค. 2026 ตลาดปรับรายชื่อทุก **ม.ค. และ ก.ค.** อย่าลืมอัปเดต
- `CRYPTO` — เพิ่ม/ลดเหรียญได้ (ใช้ชื่อย่อ เช่น `"SUI"`)
- `PARAMS` — ค่าเส้น EMA, RSI, ตัวคูณวอลุ่ม, ระยะจุดตัดขาดทุน

## รันบนเครื่องตัวเอง (ไม่บังคับ)
```bash
pip install -r requirements.txt
python signal_bot.py --market all --days 10 --ignore-date   # ไม่ตั้ง webhook = พิมพ์ผลบนจอ
python signal_bot.py --market all --backtest
```

## ข้อควรรู้
- นี่คือสัญญาณจากสูตรเทคนิค **ไม่ใช่คำแนะนำการลงทุน** กลยุทธ์ตามเทรนด์มักชนะน้อยครั้งแต่ได้กำไรก้อนใหญ่เป็นบางครั้ง และจะโดนหลอก (whipsaw) บ่อยตอนตลาดไซด์เวย์
- ผล backtest ใช้รายชื่อหุ้น SET50 ปัจจุบันย้อนไปในอดีต จึงดูดีเกินจริง (survivorship bias)
- ข้อมูล Yahoo Finance ฟรีแต่บางครั้งช้าหรือหาย ถ้าบอทแจ้งว่าดึงข้อมูลไม่ได้ ให้รอรอบถัดไป
- ใช้ repo แบบ Private: GitHub ให้นาทีรันฟรีพอสำหรับบอทนี้สบาย ๆ (รันครั้งละ ~1–2 นาที)
- ก่อนใช้เงินจริง แนะนำให้จดสัญญาณแบบ paper trade อย่างน้อย 2–3 เดือน
